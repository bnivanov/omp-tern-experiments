# Plan

The top-level block is the first run. Do not add a second `# Plan` title. When that run is closed or superseded, append `## Run <alnum-id>` with the same fields and leave every earlier section in place. Nest that later run's sections at `###` so they belong to its run heading. The latest active run is authoritative. Do not archive or overwrite to start a run. A file that already has only these top-level fields is the first run.

Each run uses `draft`, `approved`, `closed`, or `superseded`. Do not use `none`. A draft may be authorized. `Authorized by` is a quote or pointer and is required before routine work on that run. Explicit approval is for a material scope change, an irreversible action, or an unresolved tradeoff. The effective writer is the latest writer-transfer Revision on that run, otherwise `Writer`. `Run` is letters and digits only. If the runtime id has punctuation, record it in `Runtime` and generate a separate alphanumeric `Run`. Do not strip punctuation. Append writer transfers and material approvals under that run's Revisions. Do not overwrite history.

Optional labels under Boundaries may stay blank. Fill them only so a later session can find the repository, project, checkout, branch, record authority, and integration owner. They are not a status, a registry, or a required bundle. A later run keeps the labels with its other fields and leaves them blank when that run has no separate boundary.
